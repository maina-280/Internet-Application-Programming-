HTML tags and their descriptions

1. Ordered List

It is a list of items arranged in a specific sequence, usually numbered. it use
    for example:
    1. Wake up.
    2. Have breakfast.
    3. Go to school.

    2. Unordered List

    It is a list of items that do not follow a specific order and the items are marked with bullets. it use
      for example:
      • Yellow
      • Black
      • Red
